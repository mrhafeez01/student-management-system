# Student Management System

A simple Student Management System web application developed as an academic project and containerized using Docker.

## 📌 Project Overview

The Student Management System is a web-based project designed to provide a simple interface for managing student-related information.

This project was created to practice web development concepts and Docker containerization.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Docker
- Nginx

## ✨ Features

- Simple and user-friendly student management interface
- Web-based application
- Responsive and clean interface
- Docker containerization
- Easy to build and run using Docker
